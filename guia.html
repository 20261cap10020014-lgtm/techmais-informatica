Guia de Tecnologia

Como escolher um computador?

Antes de comprar um computador, é importante observar quais atividades serão realizadas.

Um equipamento utilizado apenas para navegar na internet e estudar possui necessidades diferentes de um computador utilizado para jogos ou edição de vídeos.

Processador

O processador é responsável por executar as instruções dos programas.

Alguns exemplos de fabricantes são:

Intel AMD

Memória RAM

A memória RAM armazena temporariamente os dados que estão sendo utilizados pelo computador.

Quanto maior a quantidade de memória disponível, maior pode ser a capacidade do computador de trabalhar com várias aplicações simultaneamente.

Armazenamento

Os principais tipos de armazenamento encontrados atualmente são:

HD, SSD, SATA, SSD, NVMe

Qual escolher?

HD: Indicado quando é necessário grande espaço de armazenamento por um custo menor.

SSD: Oferece maior velocidade de acesso aos dados em comparação com um HD tradicional.

SSD NVMe: Utiliza uma interface de comunicação voltada para oferecer altas velocidades de transferência.

Glossário de informática

CPU: Unidade responsável pelo processamento das instruções.

RAM: Memória utilizada temporariamente durante a execução dos programas.

SSD: Dispositivo utilizado para armazenamento de dados.

GPU, Componente responsável pelo processamento gráfico.
